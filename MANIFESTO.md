# Project Manifesto

## 📢 Core Beliefs
1. **Simplicity over Complexity:** We strive for KISS (Keep It Simple, Stupid).
2. **Speed and Safety:** Leveraging Rust, Tauri, Vue to achieve Performance First.
3. **Open Collaboration:** Our mission is Become the default OS-level orchestrator for both desktop apps and Kubernetes..

## 🎯 Our Aim
We build tools that empower developers to handle complex MLOps workflows with ease.

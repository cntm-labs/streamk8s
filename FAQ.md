# Frequently Asked Questions (FAQ)

## ❓ General
**Q: What is "StreamK8s"?**
A: StreamK8s is an AI-driven Kubernetes IDE that solves resource hogging and manual GPU switching with an ultra-intuitive, monkey-proof interface.

## 🛠️ Technical
**Q: How do I run tests?**
A: Use the command: `cargo test && npm run test`.

**Q: Which languages are supported?**
A: Primarily Rust, Tauri, Vue.

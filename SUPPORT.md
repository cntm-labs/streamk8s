# Support & Help

## 🆘 Getting Help
If you run into issues with **StreamK8s**, here is how you can get help:

1. **Check the Docs:** Start with the [README.md](README.md) and [ARCHITECTURE.md](ARCHITECTURE.md) to understand how the system works.
2. **Search Issues:** See if someone else has already reported the problem in our GitHub Issues.
3. **Open a Bug Report:** If your issue is new, please open a bug report using our [standard template](.github/ISSUE_TEMPLATE/bug_report.yml).

## 🛡️ Security Issues
Do NOT open public issues for security vulnerabilities. Please follow the policy outlined in [SECURITY.md](SECURITY.md) and email **security@cntm-labs.com**.

## 🤝 Community Discussions
For general questions or to showcase your custom extensions, join our discussions on the GitHub Repository.

# Implementation Plan: Helm, Prometheus, and AI Profiling

## Task 1: Helm Integration
- **Backend:** 
  - Create `src-tauri/src/k8s/helm.rs`.
  - Implement Tauri commands: `list_helm_releases(namespace)`, `get_helm_release_history(name, namespace)`.
  - Use `std::process::Command` to execute `helm list --namespace <ns> -o json`.
- **Frontend:** 
  - Add a "Helm Releases" tab in the Activity Bar.
  - Create `HelmReleasesView.vue` to show a data table of releases (Name, Namespace, Revision, Updated, Status, Chart, App Version).

## Task 2: Prometheus / Metrics Integration
- **Backend:** 
  - Create `src-tauri/src/k8s/metrics.rs`.
  - Fetch basic metrics from `metrics.k8s.io` (PodMetrics and NodeMetrics) via `kube-rs` if installed.
  - Implement Tauri command: `get_pod_metrics(namespace)`.
- **Frontend:** 
  - Update `DynamicResourceTable.vue` (when viewing Pods) to show CPU and Memory columns.
  - Periodically poll `get_pod_metrics` and merge data into the Pod rows.

## Task 3: AI Profiling Engine
- **Backend:** 
  - Create `src-tauri/src/k8s/ai_profiler.rs`.
  - Expose a Tauri command `analyze_workloads(context)`.
  - For MVP, implement a mock or basic heuristic AI (since we don't have API keys hardcoded) that flags high-usage deployments for suspension based on historical telemetry.
- **Frontend:** 
  - Add an "AI Insights" View (using the `ai` tab in Activity Bar).
  - Display recommendations generated by the `analyze_workloads` endpoint.

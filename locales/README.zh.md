StreamK8s 能够在运行大型桌面应用程序或游戏时，动态分配 GPU 并自动挂起后台的 Kubernetes Pod。它拥有快速的可视化仪表板、AI 智能剖析（Smart Profiling）以及类似 VSCode 的可扩展第三方扩展市场，让 Kubernetes 资源管理变得轻而易举。

## ✨ 核心特性 (Features)

- 🚀 **AI 资源管理器和动态 GPU 切换器**
- 🛡️ **带智能剖析功能的实时可视化仪表板**
- 📊 **类似 VSCode 的第三方扩展市场**

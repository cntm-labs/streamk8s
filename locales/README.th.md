StreamK8s จะจัดสรร GPU แบบไดนามิกและระงับการทำงานของ K8s pods ในพื้นหลังโดยอัตโนมัติ เมื่อมีการรันแอปพลิเคชันหรือเกมที่กินทรัพยากรสูง มาพร้อมแดชบอร์ดที่สวยงามและรวดเร็ว ระบบวิเคราะห์อัจฉริยะ (AI Smart Profiling) และตลาดส่วนขยาย (Marketplace) ที่ยืดหยุ่นเหมือน VSCode ทำให้การจัดการทรัพยากร Kubernetes กลายเป็นเรื่องง่าย

## ✨ ฟีเจอร์เด่น (Features)

- 🚀 **ระบบจัดการทรัพยากรด้วย AI และการสลับ GPU แบบไดนามิก**
- 🛡️ **แดชบอร์ดแสดงผลแบบเรียลไทม์พร้อมการวิเคราะห์อัจฉริยะ (Smart Profiling)**
- 📊 **ตลาดส่วนขยาย (Marketplace) ในรูปแบบเดียวกับ VSCode**

## 🛠️ เริ่มต้นใช้งาน (Quick Start)

```bash
# ติดตั้ง dependencies, รัน Tauri dev server และให้ StreamK8s ตรวจหา Kubeconfig ในเครื่องของคุณโดยอัตโนมัติ
```
